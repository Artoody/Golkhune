# frontend

Your web UI lives here (React / Vue / plain HTML / Vite — your choice).

## Expected role

- Show backend / ESP status
- Optionally send a test trigger to the backend

## Railway

- Root Directory: `frontend`
- Set `VITE_API_URL` (or your own env name) to your backend public URL

## Files to add

- `package.json` (if using a bundler)
- app source under `src/` or your preferred layout
