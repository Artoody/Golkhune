# esp

ESP32 firmware versions. Students write and flash / simulate these themselves.

## Versions

| Folder | Use |
|--------|-----|
| `v1-wokwi/` | Wokwi simulator sketch |
| `v2-hardware/` | Real ESP32 board sketch |

## Expected role

- Connect to your Railway backend over WebSocket (`wss`)
- Handle JSON payloads coming from n8n via the backend

Put `.ino` (or PlatformIO) files inside each version folder.
